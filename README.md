# Cachj's Storage — Forge 1.20.1

Bloque: Cachj's Chest (`cachjsstorage:cachjs_chest`).

## Crafteo
- Modo 1: clic en Fabricar = una receta; Shift + clic = una receta al inventario.
- Modo MAX: clic en Fabricar = una receta; Shift + clic = hasta 10.000 recetas por acción, limitadas por materiales y espacio de inventario.
- La cuadrícula 3x3 funciona como plantilla: los ingredientes reales se toman del almacenamiento.

## Compilar
GitHub Actions, o `gradle build` con Java 17.
